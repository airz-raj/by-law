# Security Policy

## Supported Versions

Currently, only the `main` branch is supported.

## Reporting a Vulnerability

Please report security issues by opening an issue on GitHub, or by contacting the repository owner directly if it involves a sensitive data exposure.

## Scope

- Vulnerabilities in the core parsing engine
- Dependencies in `requirements.txt` or `package.json`
- Prompt injection bypasses

We take security seriously and will attempt to address vulnerabilities promptly.
